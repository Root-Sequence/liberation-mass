# Project Context — Liberation Mass

## Purpose and scope

Liberation Mass is an open, remixable gathering practice combining **Commons**—testimony, coordination, mutual aid, and action—with **Rite**—art, ritual, food, music, rest, grief, joy, and renewal.

It is not a church, cult, festival brand, software platform, fixed doctrine, or permission to ignore local safety and consent because the format is open.

## Current reality

The repository defines principles, gathering modes, rotating roles, spaces, safety expectations, agendas, optional modules, and remix guidance. It is an active experimental commons, not a verified institution or universally safe recipe. Real gatherings must adapt to participants, place, capacity, law, access, and risk.

The README and `LICENSE` identify CC0 1.0, while `CONTRIBUTING.md` says contributions use CC BY-SA 4.0. That unresolved conflict affects contributor expectations and must not be silently interpreted as a settled dual-license or as one file automatically overriding the other.

## Repository structure

The root README carries the whole-format overview. FAQs provide accessible public routes. `docs/` owns deeper facilitation, hosting, growth, safety, ecosystem, and module material.

## Ecosystem connections

Liberation Mass is the ecosystem’s embodied-practice branch. It translates care, anti-hierarchy, access, mutual aid, stewardship, and shared meaning into actual social situations. Community Infrastructure may learn from those situations, while remaining optional and separately governed. Root Sequence supplies broader inquiry; Being Human(e) contributes human-scale tensions.

## Working rules

- Consent, exit, accessibility, aftercare, and sensitive-information boundaries come first.
- Roles share work, not unrestricted power; visibility is not authority.
- Preserve local autonomy without hiding who bears risk or labor.
- Do not publish participant identities, operational security details, or private conflict records.
- Resolve the CC0/CC BY-SA contribution conflict deliberately before presenting contributor licensing as settled.

## Update contract

Review when the Commons/Rite model, roles, safety practice, access expectations, participation routes, licensing, or ecosystem boundaries materially change.
